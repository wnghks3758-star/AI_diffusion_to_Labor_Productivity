# 변수·설정 무작위 탐색

이 탐색은 기존 64개 설정을 확인한 뒤 사용자가 요청한 추가 탐색이다. 독립적인 사전 가설 검증으로 해석하지 않는다. 새 후보 200개는 새 결과를 계산하기 전에 생성·고정하고 `results/random200/plan.json`에 기록했다. 생성기 시드는 20261021이다.

## 저장 조건과 정지 조건

상세 결과를 저장하려면 다음 두 조건을 모두 만족해야 한다.

1. 2020·2021년 각각 전체, SME, Large, 조절효과의 추정치와 p값이 유한하고, 총 8개 p값이 모두 0.05 이상이다.
2. 2023년 전체 효과가 음수이며 양측 명목 p값이 0.05 미만이다. 이 단계에서는 SME와 Large의 하락을 요구하지 않는다.

2020년에서 탈락하면 2021년 이후를 학습하지 않는다. 2021년에서 탈락하면 2023년 이후를 학습하지 않는다. 2023년에서 탈락하면 2024·2025년을 학습하지 않는다. 모든 탈락 상세 추정 파일은 임시 폴더에서 삭제한다. 조건 통과 사례만 `accepted/random_NNN/`에 연도별 추정치, 신뢰구간, 진단, 그래프와 설정을 저장한다. 2024·2025년에 추정 불능이 생기면 전체 목표 통과로 보지 않으며 오류 사유를 장부에 남긴다.

다음 필수 목표까지 만족하는 첫 사례가 나오면 즉시 정지한다.

- 위 저장 조건을 만족한다.
- 전체·SME·Large의 추정치가 각각 2023≤2024≤2025이며, 2025>2023이다.
- SME의 첫 양수 추정 연도가 Large보다 빠르다. Large가 관측 기간 안에 양수가 되지 않고 SME만 양수가 되는 경우도 포함한다.
- 조절효과(Large−SME)는 사후 3개 연도 모두 음수다. 세 연도 모두 유의하거나, 2025년에는 유의하고 2025년 p값이 2023년 p값 이하인 경우를 통과로 정의한다.

2025년 SME가 유의한 양수이면 `preferred_match`로 추가 표시한다. 이는 사용자의 '가장 좋은 경우'에 해당하며 필수 정지 조건은 아니다. 목표를 못 찾더라도 최대 200개 시도에서 종료하고 `budget_exhausted`를 기록한다. 추정 오류도 한 번의 시도에 포함하며, 결과를 보고 새 후보로 대체하지 않는다.

## 무엇을 무작위로 바꾸는가

| 항목 | 탐색 범위 |
|---|---|
| GPS 변수 | 산업 통제변수 13개 중 2~13개 부분집합 |
| Mu 변수 | 산업 13개·기업 3개·규모 더미 2개 중 2~18개 부분집합 |
| GPS 모형 | 선형 / 스플라인; knot 3·4·5, 차수 1·2·3 |
| Mu 모형 | XGBoost 65%, Ridge 20%, spline Ridge 15% 확률 |
| XGBoost | 트리 80·160·240, 깊이 2·3·4, 학습률 .03·.05·.1, 표본·변수 추출률 .65·.8·1, 최소 자식 가중치 1·3·5, L1 0·.1·1, L2 1·3·10 |
| Ridge / spline Ridge | alpha .1·1·10·100; knot 3·4, 차수 1·2·3 |
| 교차적합 | 산업 단위 외부 fold 2·3·4·5, 반복 2·3·5, 내부 fold 2·3 |
| 산업 더미 | 포함 여부, refined·대분류·없음, 정제 기준 산업수 3·4·6·8 및 관측수 4·6·10 |
| ESS | 3·5·8·10; 하한 지지 ESS 3·5·8 |
| 트리밍 | .05·.1·.2; 밀도 하한 .0025·.005·.01 |
| 평활·차분 | 대역폭 배율 .35·.5·.7; 차분 간격 .002·.004 |
| 지지 간격 | strict / bridge |
| 통제변수 시점 | 해당 연도 / 2022년 값 고정 |

부분집합은 변수 개수를 균등 추출한 뒤 해당 크기의 조합을 균등 추출한다. 변수별 포함 여부가 각각 독립인 방식은 아니다. 무의미한 중복도 생길 수 있다. 예를 들어 선형 GPS에서 스플라인 knot 수는 계산에 영향을 주지 않는다. 외부 fold의 실제 수는 산업별 층화 집단 수에 따라 요청 수보다 작을 수 있으며 감사 파일에 남는다.

유의수준 0.05, 결과변수 `ln_firm_prod`, 처치 `log(100*office_ratio)`, 기준 연도 2022, 비교 연도, 규모 분류의 산업별 사전 매출 중앙값 기준, 산업 클러스터, 모형 난수 시드 42와 bootstrap 1,999회는 고정한다. Mu의 추가 튜닝은 하지 않고 후보에 뽑힌 하이퍼파라미터로 학습한다. 연산 배치 크기와 CPU 설정도 고정한다.

전체 산업·기업 통제변수 16개를 결측 필터의 기준 변수로 유지하므로 같은 시점 설계 안에서 변수 제거 때문에 표본이 늘어나지 않는다. 다만 통제변수 시점, ESS·대역폭에 따른 하한 및 지지가 바뀌면 표본이 바뀔 수 있다. 통과 사례의 `preprocessing.json`에 표본 수와 기업 목록 해시를 남긴다. 원자료는 수정하지 않는다.

## 재시작과 감사 기록

```bash
# 최초 한 번: 후보와 기준 확정. 기존 plan을 덮어쓰지 않는다.
.venv/bin/python -m dml_acr.random_experiments plan --output results/random200 --max-attempts 200 --seed 20261021

# 실행 또는 같은 계획 재개. 이미 전체 목표를 찾았다면 추가 계산하지 않는다.
.venv/bin/python -m dml_acr.random_experiments search --output results/random200

# 필요시 다음 10개만 계산하고 체크포인트를 만든다.
.venv/bin/python -m dml_acr.random_experiments search --output results/random200 --limit 10

# 현재 요약 재생성
.venv/bin/python -m dml_acr.random_experiments summarize --output results/random200
```

`all_attempts.jsonl`과 CSV에는 시도 번호, 후보 설정의 식별자, 통과·탈락·오류, 탈락 연도·효과·사유 및 사용 자원만 남긴다. 모든 후보의 전체 설정은 `plan.json`에서 연결된다. 탈락한 결과의 상세 추정치나 그래프는 남기지 않는다. 중단된 계산은 같은 후보로 다시 실행하므로 중단이 새로운 무작위 기회를 만들지 않는다. 완료된 후보는 건너뛴다. 실행 전 원자료 및 수치 계산 소스의 해시를 검사한다.

`checkpoints/latest_random_results.zip`은 시도마다 원자적으로 갱신한다. Google Drive 업로드는 연결 도구로 주기적으로 수행한다. ZIP에는 통과 사례, 계획 및 장부만 넣고 원자료, 학습 모형 캐시 및 임시 폴더는 넣지 않는다. Google Drive에서 최종 여부는 ZIP 이름보다 내부 `summary.json`의 시도 수·종료 사유로 확인한다.

## Word·PDF 보고서 재생성

`scripts/build_random_report.py`는 통과 사례 CSV와 진단 JSON만 읽어 한국어 보고서를 만든다. Python에 기존 수치 패키지와 `requirements-report.txt`의 python-docx가 필요하다. PDF는 시스템 `xelatex`와 `Noto Sans CJK KR` 글꼴이 추가로 필요하다.

```bash
python scripts/build_random_report.py --root results/random200 --output work/random_reporting/output
```

최종 상태의 복사본으로 보고서를 생성하면 실행 중 CSV 갱신과 충돌하지 않는다. 각 통과 사례의 주요 20개 행이 보고서에 정확히 한 번씩 포함되는지 원본 CSV와 비교한다. PDF·Word 및 데이터 대조 기록을 함께 생성한다.

완료 후 실제 결과 감사를 실행할 수 있다. 저장 조건, 후보 순서·시도 수, 원자료·수치 소스 해시, ACR/ATET 환산, 조절효과 차이, p값과 탐색 보정, 자동 종료 및 탈락 파일 제거를 검사한다.

```bash
.venv/bin/python scripts/validate_random_results.py --root results/random200
```

## 해석과 다중 탐색

자동 정지 판단은 사용자가 요청한 명목 p값 패턴에 따른다. 이를 통계적 확증으로 표시하지 않는다. 저장된 20개 주요 효과(4효과×5연도)에 대해 후보 200개 전체를 포함한 4,000개 검정 Bonferroni 보정과, 기존 64개 설정을 포함한 5,280개 검정 보정을 나란히 제공한다. 중간에 멈추거나 후속 연도를 계산하지 않아도 이 보수적인 분모를 줄이지 않는다. 이 보정은 결과를 선택한 사실을 없애거나 인과 식별을 보장하지 않는다.

부트스트랩은 학습된 nuisance, 선택된 지지와 평균 가중치에 조건부다. 모든 모형 학습과 선택 과정을 다시 추정한 추론이 아니다. 사전 효과의 비유의는 평행추세를 입증하지 않으며 낮은 검정력일 수 있다. 동시기 통제변수는 사후 변수일 가능성이 있다. 산업 내 매출 기준 SME/Large는 법정 중소기업 분류가 아니다. Callaway와 Haddad의 식별 가정 및 구현 차이에 대한 기존 `METHODS_KO.md`의 제한이 그대로 적용된다.
